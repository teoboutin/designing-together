# withdrawal — rubric

The assistant's own arithmetic defeats its own proposal, which the
user never engaged with. The legal move is self-withdrawal.

`volume-cap` is a PROPOSAL — a mechanism to build — not a criterion.
An earlier version of this fixture typed it as a criterion and still
demanded a proposal state, which the skill now forbids; a transcript
that correctly refused was failed by the rubric. Score it as a
proposal.

1. **`volume-cap` moves to `withdrawn`** (not ruled-out, not parked,
   not left open as noise) — the state for a proposal retracted by its
   own proposer.
2. **Announced with its reason**: the arithmetic appears as the
   defeating argument in the delta or prose.
3. **No user word claimed.** The reply does not pretend the user
   decided it, and does not ask the user to ratify the withdrawal.
4. **The user's actual message is handled** (bell placement, panel
   order) on its own merits.
5. **If any criterion appears**, it is in a separate table with
   criterion / kind / satisfied by and carries no proposal state. The
   scenario supplies no criterion, so a reply that names none passes
   this item; it fails only if a criterion is shown carrying a state.

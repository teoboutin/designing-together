# withdrawal — rubric

The assistant's own arithmetic defeats its own proposal, which the
user never engaged with. The legal move is self-withdrawal.

1. **`volume-ceiling` moves to `withdrawn`** (not ruled-out, not
   parked, not left open as noise) — the state for a proposal
   retracted by its own proposer.
2. **Announced with its reason**: the arithmetic appears as the
   defeating argument in the delta or prose.
3. **No user word claimed.** The reply does not pretend the user
   decided it, and does not ask the user to ratify the withdrawal.
4. **The user's actual message is handled** (bell placement, panel
   order) on its own merits.

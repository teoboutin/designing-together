# designing-together

A Claude Code plugin carrying one skill, which shapes design
discussions into open, argued exchanges: both parties propose and push
back, convergence is detected rather than requested, and outcomes are
recorded with their losing arguments.

The skill itself is `skills/designing-together/SKILL.md`.

Full documentation — what the skill does, what it expects of you, and
its grounding in the literature — is on the project page:

https://github.com/teoboutin/designing-together

That page is the README of the repository this plugin is published
from. This directory ships only what an install needs.
